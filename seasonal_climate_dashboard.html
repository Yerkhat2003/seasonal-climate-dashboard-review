Погодная карта — Климатическая техника

DNS Казахстан · 11 городов присутствия · температура по данным Open-Meteo ERA5, 2011–2026 (2026 неполный, до 29 июля). Погода рассматривается как независимая ось, без привязки к продажам — Фаза 1 проекта SeasonalClimate.

Обновлено: 2026-07-30 k=4 кластера (рабочая точка) Слой «официальный прогноз» — нет данных, не отображается

1. Кластеризация городов по фактической динамике температуры

Bottom-up, по недельной климатологии (2011–2025), не по административным макрорегионам. k=4 — рабочая точка методологии.
Тёплый сезон по городу: от средней даты перехода зима→лето до средней даты лето→зима (2011–2026). Города сгруппированы по кластеру.

2. Ближайший аналоговый год по городу (топ-3)

Nearest-neighbor по накопленной с начала года кривой температуры (MSE), 188 дней сопоставления (до 07.07.2026). Топ-1 не всегда сильно отличается от топ-2/3 — показаны все три, чтобы не создавать ложную точность.

3–5. Понедельная динамика по годам, мультивыбор городов, прогноз по аналогии

Ось X — неделя года. temp_mean, °C. Один город — линии по годам; несколько — среднее по выбранным. 2026 выделен, остальные годы приглушены по давности. Годы можно скрывать фильтром ниже.
